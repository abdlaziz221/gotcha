Un autre agent : ajoutez l'adresse ci-dessus comme serveur MCP HTTP (« streamable »), dans le format de sa documentation.

La première fois

  1. Ajoutez l'adresse

    Avec la configuration de votre agent, puis redémarrez-le si besoin.

    2. {% if page.login_required %}

  2. Connectez-vous avec GitHub

    À la première utilisation, l'agent ouvre votre navigateur sur Gotcha. Le compte est gratuit, et aucune permission sur vos dépôts n'est demandée. Aucun jeton à copier.

  3. Autorisez l'outil

    Gotcha affiche le nom de l'outil et l'adresse où il recevra son accès. Acceptez seulement si vous venez de lancer cette connexion vous-même.

    4. {% else %}

  4. Rien d'autre à faire

    Sur ce serveur, la lecture est libre : aucune connexion n'est demandée.

    5. {% endif %}

  5. Posez votre question comme d'habitude

    Par exemple : « Ajoute le paiement Wave au Sénégal ». L'agent consulte Gotcha avant d'écrire le code et vous signale les pièges et les pannes en cours.

Ce que votre agent peut faire

Les outils du serveur MCP.

  • list_servicesLister les services couverts, une fiche par pays.Lecture
  • get_ficheLire une fiche : étapes, pièges, bac à sable et production, état.Lecture
  • search_gotchasChercher un piège par mot-clé, en-tête HTTP, code d'erreur ou symptôme.Lecture
  • get_service_statusConnaître l'état d'un service dans un pays, avec ses pannes.Lecture
  • report_outageSignaler une panne observée (paiements en échec ou sans réponse). Nombre limité.Signalement
    • {% if page.login_required %}
  • propose_gotchaProposer un piège résolu, après votre accord sur le brouillon. Un humain le relit avant publication.Connecté
  • confirm_gotchaDire si un piège s'applique encore, avec une preuve. Compte une fois par mois.Connecté
